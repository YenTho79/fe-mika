# Mika Books Mobile

Ứng dụng đọc truyện xây dựng bằng React Native, Expo Router và AsyncStorage. Bản hiện tại chạy hoàn toàn bằng dữ liệu local, không cần backend.

## Chạy dự án

```bash
npm install
npm start
```

Tài khoản demo: `user@mika.vn` / `12345678`.

Dữ liệu mẫu được seed trong lần chạy đầu và mọi thay đổi tiếp theo được lưu bằng AsyncStorage. Có thể build Web bằng:

```bash
npx expo export --platform web
```
